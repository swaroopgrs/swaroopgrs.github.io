## How to Write Blog Posts

Just create a new Markdown file in the `_posts` folder with this naming format:

```
YYYY-MM-DD-your-post-title.md
```

For example: `2026-02-05-my-first-post.md`

## Front Matter

At the top of your post, add this header (called "front matter"):

```yaml
---
title: "Your Post Title"
date: 2026-02-05
category: AI/ML
description: A brief description of your post.
---
```
