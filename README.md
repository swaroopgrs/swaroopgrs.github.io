# Swaroop Gadiyaram - Personal Website

🌐 **Live Site:** [swaroopgrs.github.io](https://swaroopgrs.github.io)

Personal website with academicpages-style layout.

## Structure

```
index.html          # About page (home)
blog.html           # Blog listing
posts/              # Blog posts
  reference.html    # Post template
css/styles.css      # Styles
js/script.js        # Theme toggle
```

## Deployment

Push to `main` → auto-deploys via GitHub Actions.

## Adding Blog Posts

1. Copy `posts/reference.html`
2. Update content
3. Add entry to `blog.html`
4. Push

## Local Dev

```bash
npx serve
```
