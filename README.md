## 🚀 Deployment

**CI/CD is set up!** Any push to `main` will automatically deploy.

### First-time Setup

1. Go to GitHub repository → **Settings** → **Pages**
2. Under "Build and deployment", select **GitHub Actions**

### Deploy

```bash
git add .
git commit -m "Update"
git push
```

## ✍️ Adding Blog Posts

1. Copy `posts/rag-pipelines.html` as template
2. Update content
3. Add link in `blog.html`
4. Push
